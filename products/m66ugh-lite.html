M66UGH-Lite Geodetic GNSS Receiver Cost-Effective Multi-Constellation GNSS Base Station

Key Features

1408-Channel Engine

Supports GPS, GLONASS, BDS, Galileo, QZSS, SBAS and NavIC across 1,408 tracking channels for maximum satellite visibility.

Sub-Centimeter RTK

RTK accuracy of ±8mm+1ppm horizontal and ±15mm+1ppm vertical. Static accuracy of ±2.5mm+0.5ppm for geodetic control networks.

IP68 Sealed

Fully submersible IP68 casing with industrial-grade magnesium-aluminum alloy construction. Operates from -40°C to +85°C.

ARM Cortex-A7 Linux

1.8GHz ARM Cortex-A7 processor running Linux OS for open-platform integration with CORS software and third-party systems.

32 GB Storage

24 GB available data storage with circular multi-channel recording. Handles long-term CORS logging without manual intervention.

Ethernet + 4G/LTE

Multiple interfaces: Ethernet, RS232, USB, and 4G LTE. Accepts 9–24V DC input for flexible field and base station power setups.
